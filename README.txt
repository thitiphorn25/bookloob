BOOKLOOP — START HERE

ไฟล์ในโปรเจกต์:
- index.html  โครงสร้างหน้าเว็บ
- style.css   รูปแบบ สี และ responsive design
- script.js   ข้อมูลหนังสือและการทำงานของปุ่มต่าง ๆ

วิธีเปิด:
1. แตกไฟล์ BookLoop.zip
2. เปิดโฟลเดอร์ BookLoop ใน VS Code
3. เปิด index.html ด้วย Live Server (แนะนำ) หรือดับเบิลคลิกเปิดในเบราว์เซอร์
4. ลองค้นหาหนังสือ กดหัวใจ เปิดรายละเอียด และกด "ลงหนังสือ"

หมายเหตุ:
- เว็บต้นแบบใช้ localStorage ข้อมูลจะอยู่ในเบราว์เซอร์และเครื่องนี้เท่านั้น
- คำขอรับ/แลก/ซื้อเป็นการจำลอง ยังไม่ได้ส่งข้อความถึงผู้ลงประกาศจริง
- หนังสือ 12 รายการแรกเป็นข้อมูลตัวอย่างสำหรับสาธิต
- ถ้าต้องการกลับไปข้อมูลเริ่มต้น ให้เปิด Developer Tools > Application > Local Storage
  แล้วลบ key: bookloop-books-v1, bookloop-saved-v1, bookloop-requests-v1
- รูปปกหนังสือจริงบางรายการโหลดจาก Open Library โดยใช้ ISBN และต้องใช้อินเทอร์เน็ต หากไม่พบปกหรือโหลดไม่สำเร็จ เว็บจะแสดงปกกราฟิกสำรองแทน รายการที่ผู้ใช้เพิ่มเองสามารถใส่ URL รูปปกได้
